Recent changes

Newest entries first.

  1. July 7, 2026

    Phase 2 UI shell refactor completed

    Completed the shared UI cleanup pass so module pages now sit on a cleaner shell/CSS structure before the pricing-first modularization work starts.

    • Shared CSS split into `tokens`, `base`, `components`, and `shell` layers.
    • Shell-page inline styles moved into external page CSS files.
    • Service worker cache list updated for the new shared CSS layout.
  2. Recent

    Authenticated platform shell hardened

    Shared sign-in, protected module screens, and the launch pad flow now operate behind the same platform auth layer so internal tools stay on one controlled entry point.

  3. Earlier

    Delivery and export groundwork

    Built the initial delivery and export workflow around app-owned shipment state, archive access, and the private app database so the module can evolve without overwriting source systems.

Historic source systems remain read-only during discovery. App-owned state lives in the private OptiLens Local database first.
